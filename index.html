donut uploader

YouTube 채널 도넛역학 운영자의 개인용 업로드 도구

donut uploader 는 도넛역학 채널 운영자가 자기 PC 에서 직접 만든 교육용 짧은 영상(구조공학·교량 내진성능평가 해설)을 자기 채널에 올리고, 제목·설명·번역·재생목록·공개 상태를 관리하려고 만든 프로그램입니다. 일반에 배포하거나 다른 사람의 계정에 쓰는 서비스가 아닙니다.

  • 쓰는 Google API: YouTube Data API v3
  • 하는 일: 채널 확인, 영상 업로드, 영상 정보·공개 상태 변경, 재생목록 관리
  • 개인정보 처리: 개인정보처리방침

English

donut uploader is a personal tool used only by the owner of the YouTube channel 도넛역학 (donut_Civil.E) to upload the channel's own educational short videos from the owner's PC and to manage their titles, descriptions, translations, playlists and privacy status. It is not offered to the public and does not act on anyone else's account.

  • Google API used: YouTube Data API v3
  • What it does: confirm the channel, upload videos, update video metadata and privacy status, manage playlists
