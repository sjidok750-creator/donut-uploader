개인정보처리방침

donut uploader · 시행일 2026년 10월 28일 · 앱 소개

1. 누가 쓰는가

donut uploader 는 YouTube 채널 도넛역학 운영자 한 사람이 자기 채널을 관리하려고 쓰는 개인용 프로그램입니다. 다른 사람이 로그인해 쓰는 서비스가 아닙니다.

2. 접근하는 Google 사용자 데이터

  • 권한 범위: YouTube Data API v3 의 youtube.force-ssl
  • 읽는 것: 로그인한 채널의 이름·핸들·ID(올바른 채널인지 확인), 운영자가 올린 영상의 상태(처리·공개 여부), 운영자의 재생목록
  • 쓰는 것: 운영자가 만든 영상 업로드, 그 영상의 제목·설명·태그·번역·공개 상태 변경, 운영자 재생목록에 영상 추가

3. 저장과 전송

  • Google 인증 토큰은 운영자 PC 안에만 저장하며, 다른 서버나 제3자에게 보내지 않습니다.
  • 개발자가 운영하는 서버가 없습니다. 모든 요청은 운영자 PC 에서 Google 로 바로 갑니다.
  • 다른 사람의 개인정보를 모으지 않고, 광고·분석·판매에 쓰지 않으며, 제3자와 공유하지 않습니다.

4. Google API 사용자 데이터 정책

Google API 에서 받은 정보의 사용과 다른 앱으로의 전송은 Google API Services User Data Policy(제한적 사용 요건 포함)를 따릅니다.

5. YouTube API 서비스

이 프로그램은 YouTube API 서비스를 사용합니다. 사용자는 YouTube 서비스 약관과 Google 개인정보처리방침을 따릅니다.

6. 권한 철회

Google 계정의 타사 앱 및 서비스 연결 페이지에서 언제든 donut uploader 의 접근 권한을 해제할 수 있습니다. 해제하면 PC 에 남은 토큰은 더 이상 쓸 수 없습니다.

7. 문의

이 저장소의 Issues 또는 YouTube 채널 도넛역학.

Privacy Policy (English)

Effective October 28, 2026

1. Who uses it

donut uploader is a personal program used only by the owner of the YouTube channel 도넛역학 (donut_Civil.E) to manage that channel. It is not a service other people sign in to.

2. Google user data accessed

  • Scope: youtube.force-ssl of the YouTube Data API v3
  • Read: the signed-in channel's name, handle and ID (to confirm the correct channel), the processing and privacy status of the owner's uploads, and the owner's playlists
  • Write: upload the owner's own videos, update their title, description, tags, translations and privacy status, and add them to the owner's playlists

3. Storage and transfer

  • The Google authorization token is stored only on the owner's PC and is never sent to any other server or third party.
  • There is no developer-operated server; every request goes directly from the owner's PC to Google.
  • No personal data of other people is collected, and no data is used for advertising, analytics or sale, or shared with third parties.

4. Google API user data policy

donut uploader's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

5. YouTube API Services

This program uses YouTube API Services. Users are bound by the YouTube Terms of Service and the Google Privacy Policy.

6. Revoking access

Access can be revoked at any time on the Third-party apps & services page of the Google Account; the token left on the PC then stops working.
